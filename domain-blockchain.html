Teaching Philosophy
Designed for slow learners · Zero prior background required
Analogy Before Abstraction

Every concept starts with a real-world analogy before technical detail — e.g. 'a hash is like a fingerprint'.

Demonstrate Then Do

Every lab starts with a live instructor walkthrough. Students copy a working example before modifying it.

Min & Stretch Goals

Every lab specifies a minimum passing target AND a stretch goal — no one waits, no one is left behind.

Peer Programming

Used in the first 6 labs of Course 3. Two students, one computer — builds confidence and accelerates learning.

Explain Your Code

Every submission requires one-line comments on every function. Students explain code verbally during demos.

Ethereum + Solana Side by Side

From Course 2, every architectural concept is shown on both platforms. Graduates have genuine multi-chain competency.

Research Capped at 10%

No course requires more than 10% research. All remaining weight is applied labs, projects, and demonstrations.

Semester 1
3 Courses · 10 Credits · Weeks 1–16
Phase 1 — Conceptual Foundations
CUBD1091

Foundations of the Decentralised Internet

1-2-0 · 3 cr
Concepts + Economics · Sem 1, Wk 1
  • Web1 → Web2 → Web3 evolution & the case for decentralisation
  • Money, the 2008 crisis, and why Bitcoin was invented
  • Cryptography basics — hash functions, keys, digital signatures
  • Tokenomics, CBDCs, e-Rupee, and Metaverse economies
  • The blockchain ecosystem map — DeFi, NFTs, DAOs, wallets
Prereq: Basic computer literacy only
CUBD1092

Blockchain Architecture & How It Works

1-2-0 · 3 cr
Architecture + Tools · Sem 1, Wk 6
  • Merkle trees, hash pointers, UTXO vs. account model
  • Proof of Work vs. Proof of Stake · The Merge (Sep 2022)
  • Ethereum architecture — EVM, Execution Layer, Beacon Chain
  • Solana — Proof of History, Tower BFT, Sealevel parallel execution
  • Layer 2 rollups (Arbitrum, zkSync) · The Blockchain Trilemma
Prereq: CUBD1091
CUBD1093

Smart Contract Development

1-2-1 · 4 cr
Solidity + Solana Dev · Sem 1, Wk 11
  • Solidity — data types, mappings, events, modifiers, inheritance
  • ERC-20 fungible tokens with OpenZeppelin
  • ERC-721 NFTs with IPFS metadata via Pinata
  • Foundry toolchain — Forge, Anvil, Cast; test coverage & gas reports
  • Security — reentrancy, overflow, access control; Slither analysis
  • Solana Anchor framework — counter program + SPL tokens
Prereq: CUBD1091 + CUBD1092
Semester 2
3 Courses · 12 Credits · Weeks 1–16
Phase 2 — Advanced Practice
CUBD1094

Full Stack Web3 Development

1-2-1 · 4 cr
Full-Stack DApp Dev · Sem 2, Wk 1
  • React + wagmi + viem + RainbowKit — wallet connection & on-chain reads
  • Writing transactions with real-time pending/success/error states
  • The Graph — subgraph deployment, GraphQL queries in React
  • Sign-In with Ethereum (SIWE, EIP-4361) via Next.js
  • NFT minting DApp — IPFS upload, mint, gallery display
  • Solana Wallet Adapter; deploy to Vercel + Sepolia testnet
Prereq: CUBD1093
CUBD1095

Advanced Blockchain & Industry Applications

1-2-1 · 4 cr
DeFi + Security + Fabric · Sem 2, Wk 5
  • AMM design — Uniswap v2 constant product formula x·y=k
  • Lending protocols (Aave mechanics), staking reward accumulators
  • DAO governance — OpenZeppelin Governor + TimelockController
  • NFT marketplace — listing, buying, EIP-2981 royalties
  • Security audit methodology — Slither, Aderyn, audit reports
  • Hyperledger Fabric — peers, orderers, channels, Go chaincode

Capstone
CUBD1096  ·  0-0-4  ·  4 Credits  ·  Sem 2 Wk 9–16

Capstone Project in Blockchain Engineering

Teams of two build and deploy a complete blockchain project over 8 weeks. Plan, architect, code, test, secure, and ship. Reviewed by faculty and an industry guest. All 5 tracks require a live Vercel URL and a verified testnet deployment.

A DeFi DApp

B NFT Platform

ERC-721 collection + marketplace or minting DApp on Eth or Solana

C DAO App

Governance token + Governor + Timelock + proposal & vote DApp

D Security Audit

Slither + manual audit + 1500-word report + 5 findings + fixes

E Hyperledger App

Fabric 2-org network + Go chaincode (5 functions) + Node.js client
